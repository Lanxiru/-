## 图像提示词质量标准

优秀的图像提示词应满足：

- 明确图纸类型和视角。
- 明确基地约束和不可改变元素。
- 描述空间结构，而不只是风格词堆叠。
- 包含关键规划要素：道路、建筑、绿地、水系、节点、活动人群。
- 指定表达风格：竞赛图纸、教学汇报、手绘、拼贴、轴测、极简分析图等。
- 包含负面提示词，减少错误文字、比例混乱、水印和无关元素。
