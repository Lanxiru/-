# 产品完成度与使用指南

## 1. 现在产品设计完成了吗？

结论：**已经完成了 MVP 级别的产品设计与可操作前端原型，但还不是完整上线版产品**。

当前仓库已经具备：

- 智能体定位、能力边界和系统提示词。
- 任务书采集、现状图读图、图像提示词生成等模板。
- 对话式工作流、输出规范、模型调用策略和前端实施方案。
- 一个可在浏览器中打开的静态网页原型，用于录入资料、预览现状图并生成结构化模型请求。

当前仓库暂未包含：

- 后端服务。
- 数据库和用户登录。
- 真实 AI 模型 API 调用。
- 在线图片生成与图片历史管理。
- CAD/GIS 图层编辑、面积自动测算或规范数据库。

因此，它适合用于：

1. 课程设计中的个人辅助工具。
2. 智能体产品原型展示。
3. 后续开发真实 Web 应用的需求文档和前端雏形。

## 2. 你现在可以怎么使用？

### 用法 A：最快使用，作为 ChatGPT/大模型提示词包

适合你现在马上用来做课程设计。

1. 打开 `prompts/system_prompt.md`。
2. 把里面的内容复制到 ChatGPT、自定义 GPT、Coze、Dify 或其他 Agent 平台的系统提示词中。
3. 按 `templates/project_brief_template.md` 填写你的任务书信息。
4. 如果有现状图，按 `templates/site_image_review_template.md` 补充边界、道路、出入口、保留要素等说明。
5. 让智能体先输出“已知条件—未知条件—约束—机会点”。
6. 再让智能体生成 2–3 个概念方案并比较优缺点。
7. 最后按 `templates/image_prompt_template.md` 输出总平面、鸟瞰、轴测或节点图提示词。

推荐开场输入：

```text
你现在是我的城乡规划方案共创助手。我会给你任务书和现状图信息，请先整理已知条件、未知条件、设计约束和机会点，不要直接给最终方案。然后给我 2–3 个可比较的概念方案，并说明每个方案适合怎么画成图。
```

### 用法 B：使用网页原型整理资料

适合你想要一个可操作网页来录入项目资料。

在仓库根目录运行：

```bash
./scripts/start_web.sh
```

如果不用脚本，也可以运行：

```bash
python3 -m http.server 8000 --bind 0.0.0.0 --directory web
```

然后打开：

```text
http://localhost:8000
```

如果浏览器提示 `ERR_CONNECTION_REFUSED`，请确认启动命令仍在运行，并在容器或远程环境中使用端口转发地址；详细排查见 `web/README.md`。

你可以在网页里完成：

- 填写项目名称、基地背景和任务书。
- 上传现状图并本地预览。
- 填写保留要素、限制条件和设计偏好。
- 选择当前阶段和图像类型。
- 点击“生成智能体请求”。
- 复制生成的结构化请求，粘贴到 ChatGPT 或你接入的后端模型中。

注意：当前网页原型**不会直接调用 AI 模型**，它主要负责整理输入和生成请求。

### 用法 C：继续开发成完整 Web 产品

适合你希望把它做成真正的在线工具。

建议下一步开发顺序：

1. 保留现有 `web/` 静态原型作为前端交互草图。
2. 新增后端接口 `/api/chat`，用于调用文本大语言模型。
3. 新增后端接口 `/api/analyze-image`，用于上传现状图并调用多模态视觉模型。
4. 新增后端接口 `/api/generate-image`，用于把最终提示词发送给图像生成模型。
5. 加入项目保存、方案版本管理和图片历史记录。

不要把模型 API Key 写在前端页面中，应由后端安全读取环境变量。

## 3. 推荐的学习/课程工作流

如果你正在做一个真实课程题目，可以按下面顺序使用：

### 第一步：输入任务书

把任务书、指标、基地面积、用地性质、老师要求粘贴给智能体。

要求智能体输出：

- 已知条件表。
- 未知条件表。
- 硬性约束。
- 可能机会点。
- 需要你补充的 3–5 个问题。

### 第二步：输入现状图信息

如果平台支持图片，直接上传现状图；如果不支持，就手动描述：

- 基地边界。
- 周边道路。
- 水体、绿地、山体或高差。
- 保留建筑。
- 主要出入口。
- 噪声、污染、不良界面。
- 老师强调的重点。

### 第三步：生成概念方案

要求智能体生成 2–3 个方案，每个方案包含：

- 概念名称。
- 空间结构。
- 功能组织。
- 交通策略。
- 景观生态策略。
- 优点与风险。
- 图面表达方式。

### 第四步：选择一个方案深化

你选择一个方案后，让智能体继续深化：

- 总平面结构。
- 功能分区。
- 道路与慢行系统。
- 公共空间节点。
- 建筑体量和高度关系。
- 规范风险待核查项。

### 第五步：转成图像提示词

当方案稳定后，再让智能体输出：

- 总平面示意图提示词。
- 鸟瞰图提示词。
- 轴测分析图提示词。
- 节点效果图提示词。
- 负面提示词。
- 需要保持不变的现状约束。

## 4. 你下一步可以做什么？

如果你的目标是完成课程作业：

- 直接使用 `prompts/system_prompt.md` 和模板开始和智能体对话。
- 用 `web/` 原型整理任务书和现状图信息。
- 把生成的图像提示词复制到你常用的出图工具中。

如果你的目标是开发产品：

- 先用静态原型验证交互流程。
- 再做后端模型调用。
- 最后做账号、项目保存、图像生成和方案版本管理。

如果你的目标是继续完善仓库：

- 可以优先补一个后端示例。
- 可以把静态页面升级为 React 或 Next.js。
- 可以增加“现状图标注”和“方案版本对比”。
