# 是否需要调用 AI 模型

结论：**需要调用 AI 模型，但不一定每一步都需要调用同一种模型**。这个项目本身是一个提示词包、模板和智能体蓝图，不包含可执行的模型服务；真正运行时，需要把这些提示词和知识文件交给大语言模型或多模态模型来完成对话、读图、推理和提示词生成。

## 1. 最小可用版本

如果只是做“任务书解析、方案讨论、规范风险提示、图像提示词生成”，最小版本只需要调用一个**文本大语言模型**。

```text
用户输入任务书文字
  ↓
文本大语言模型
  ↓
输出：设计条件表、方案比较、深化建议、图像生成提示词
```

适合场景：

- 用户能把任务书、指标、基地条件用文字说清楚。
- 现状图只作为参考，由用户人工描述关键要素。
- 暂时不需要模型直接看图。

## 2. 推荐版本

如果希望实现“上传现状图 → 智能体读图 → 边聊边生成符合现状约束的示意图提示词”，推荐调用：

1. **文本大语言模型**：负责任务书解析、方案推理、规范风险提示和提示词输出。
2. **多模态视觉模型**：负责理解现状图、航拍图、手绘草图、任务书截图中的空间要素。
3. **图像生成模型**：负责根据最终提示词生成鸟瞰、轴测、总平面风格图或节点效果图。

```text
任务书文字 ───────────────┐
现状图 / 航拍 / 草图 ──→ 多模态视觉模型 ──→ 现状要素摘要
用户偏好 / 老师要求 ─────┘                 ↓
                                  文本大语言模型
                                         ↓
                         方案说明 + 规范风险 + 图像提示词
                                         ↓
                                  图像生成模型
                                         ↓
                              示意图 / 鸟瞰图 / 节点图
```

## 3. 分阶段模型调用建议

| 阶段 | 是否必须调用模型 | 推荐模型类型 | 说明 |
| --- | --- | --- | --- |
| 任务书解析 | 是 | 文本大语言模型 | 把任务书转为已知条件、未知条件、硬性约束和设计问题 |
| 现状图识别 | 可选但推荐 | 多模态视觉模型 | 用户上传图片时使用；如果没有视觉模型，可让用户人工标注和描述 |
| 概念方案生成 | 是 | 文本大语言模型 | 生成 2–3 个可比较方案，并说明优缺点 |
| 方案深化 | 是 | 文本大语言模型 | 根据用户反馈迭代功能、交通、景观、形态和节点 |
| 规范风险自检 | 是 | 文本大语言模型 + 知识库 | 只能做风险提示；真实合规需核查最新法定文件 |
| 图像提示词转换 | 是 | 文本大语言模型 | 把方案转成中文/英文提示词、负面提示词和参数建议 |
| 图片生成 | 可选 | 图像生成模型 | 只有当用户需要直接出图时才调用 |

## 4. 不同部署方式

### 方式 A：只做对话助手

- 需要：文本大语言模型。
- 不需要：图像生成模型。
- 输出：方案文字、表格、总平面表达建议、可复制的图像提示词。

### 方式 B：做读图方案助手

- 需要：文本大语言模型 + 多模态视觉模型。
- 不一定需要：图像生成模型。
- 输出：现状图诊断、基地问题机会矩阵、方案建议、图像提示词。

### 方式 C：做完整出图智能体

- 需要：文本大语言模型 + 多模态视觉模型 + 图像生成模型。
- 输出：方案对话、现状图解读、图像提示词、生成图像。
- 注意：生成图像通常是表达辅助，不能当作法定图纸或施工图。

## 5. 何时不需要调用图像生成模型

以下情况不需要调用图像生成模型：

- 用户只想要方案构思或设计逻辑。
- 用户只需要 Midjourney、Stable Diffusion、DALL·E 等工具的提示词。
- 用户后续会自己把提示词复制到其他出图平台。
- 用户需要的是规范自检、功能面积表、交通组织建议或汇报文本。

## 6. 成本与效果建议

- 前期讨论阶段：优先调用文本模型，成本低、迭代快。
- 上传现状图阶段：只在需要识别图像要素时调用视觉模型。
- 最终表达阶段：在方案相对稳定后再调用图像生成模型，避免频繁返工。
- 如果预算有限，可以先让用户人工描述现状图，再由文本模型生成方案和提示词。

## 7. 实现提醒

- 本仓库不包含模型密钥、后端 API 或前端界面。
- 若接入外部模型，应在平台或后端中安全保存 API Key，不要提交到仓库。
- 图像识别结果应让用户确认，尤其是红线边界、保留建筑、水体、道路和比例尺。
- 涉及规范、控规和审批时，模型只做辅助提示，最终依据应来自官方文件和专业审查。
