# 对话式规划方案工作流

## 阶段 1：资料接收与任务拆解

**目标**：把任务书变成设计问题清单。

智能体应输出：

| 模块 | 内容 |
| --- | --- |
| 项目背景 | 城市/区位、基地面积、项目类型、服务对象 |
| 硬性要求 | 用地性质、容积率、建筑密度、绿地率、限高、停车、保留要素 |
| 成果要求 | 总平面、分析图、鸟瞰、节点、剖面、模型、汇报文本 |
| 评分重点 | 概念、功能、交通、生态、规范、表达 |
| 缺失信息 | 需要用户补充或暂定假设的内容 |

## 阶段 2：现状图识别与基地诊断

**目标**：从现状图中提取可影响方案的要素。

建议按以下顺序读图：

1. 基地边界与红线关系。
2. 周边道路、公交站、地铁站、停车与可达性。
3. 现状建筑、保留建筑、拆改潜力与界面问题。
4. 地形、水系、绿地、古树、视线廊道与生态斑块。
5. 噪声、污染、背街界面、安全隐患与城市断点。
6. 人群活动、公共服务短板和潜在节点。

输出建议使用“问题—机会—设计回应”矩阵，方便转化为分析图。

## 阶段 3：概念生成

**目标**：形成 2–3 个方向鲜明的概念方案。

每个方案应包括：

- 概念名称：例如“蓝绿缝合”“公共客厅”“慢行环+活力核”。
- 空间结构：一轴、一环、多核、组团、廊道、网格或混合结构。
- 适用逻辑：解决什么现状问题，强化什么资源。
- 主要风险：指标、交通、造价、维护或表达难点。
- 图面表达：总平面上应如何画出该概念。

## 阶段 4：总平面深化

**目标**：把概念转化为可画的总平面。

深化清单：

- 功能分区：居住、商业、公共服务、教育、办公、产业、绿地、广场等。
- 交通组织：机动车出入口、消防通道、慢行系统、人车分流、停车策略。
- 开放空间：主广场、口袋公园、滨水空间、社区花园、儿童/老人活动场地。
- 开发强度：高度分区、建筑体量、界面连续性、天际线。
- 生态策略：雨洪管理、海绵设施、绿廊、透水铺装、生境修复。
- 节点设计：入口、核心广场、景观桥、街角、公共建筑首层。

## 阶段 5：规范与可实施性自检

**目标**：在图面表达前发现明显风险。

常见核查项：

- 用地性质与功能是否匹配。
- 建筑退界、间距、日照、限高是否需要核查。
- 消防车道、登高面、转弯半径是否预留。
- 道路开口位置是否避开交叉口冲突。
- 停车、非机动车、装卸、垃圾收集与应急通道是否考虑。
- 公共服务设施服务半径是否合理。
- 慢行连续性、无障碍与安全照明是否表达。
- 生态红线、河道蓝线、历史保护线等是否被触碰。

## 阶段 6：图像提示词生成

**目标**：把规划方案转为图像模型能理解的描述。

根据成果选择不同提示词：

- 总平面示意图：强调用地色块、道路、绿地、水系、图例、北箭头。
- 鸟瞰效果图：强调整体空间、建筑体量、景观系统、人群活动。
- 轴测分析图：强调分层、箭头、功能标签和透明体块。
- 节点效果图：强调人视角、材质、活动场景和空间氛围。
- 剖面透视图：强调地形、水岸、建筑高度、树阵、慢行路径。
