# 怎么打开智能体使用

你现在有两种使用方式：

1. **打开网页原型使用**：适合先把任务书、现状图、设计偏好整理成结构化模型请求。
2. **在 ChatGPT / 自定义 GPT / Coze / Dify 中使用智能体提示词**：适合真正开始和 AI 对话、生成方案与图像提示词。

## 方式一：打开网页原型

### 第 1 步：在仓库根目录启动服务

```bash
./scripts/start_web.sh
```

启动成功后，终端会显示类似内容：

```text
Starting Urban Planning Studio Copilot web prototype...
Local URL:      http://127.0.0.1:8000
Bind address:   0.0.0.0:8000
Serving folder: .../web
```

### 第 2 步：在浏览器打开地址

如果你是在本机运行，打开：

```text
http://127.0.0.1:8000
```

或：

```text
http://localhost:8000
```

如果你是在远程容器、Codespaces、云 IDE 或服务器里运行，不要直接打开 `127.0.0.1`，而要打开平台提供的 **Ports / Forwarded Port / 端口转发** 链接。

### 第 3 步：在网页里填写资料

网页里按顺序填写：

1. 项目名称。
2. 城市与基地背景。
3. 任务书、指标和老师要求。
4. 上传现状图或航拍图。
5. 填写保留要素、限制条件和设计偏好。
6. 选择当前阶段，例如“任务解析、现状诊断、概念方案、方案深化、规范自检、图像提示词”。
7. 点击“生成智能体请求”。
8. 点击“复制”，把生成内容粘贴给 ChatGPT 或你自己的后端模型。

注意：当前网页原型只是帮你整理资料和请求，**不会直接生成最终方案**。真正方案生成需要把复制出来的请求发给大语言模型。

## 方式二：直接在 ChatGPT / Agent 平台中使用

如果你想真正“打开智能体对话”，按下面做：

### 第 1 步：复制系统提示词

打开：

```text
prompts/system_prompt.md
```

把里面的全部内容复制到：

- ChatGPT 的自定义指令或自定义 GPT Instructions；
- Coze / Dify / FastGPT 的 system prompt；
- 你自己后端调用模型时的 system message。

### 第 2 步：复制项目资料模板

打开：

```text
templates/project_brief_template.md
```

按模板填写你的任务书信息。如果有现状图，再参考：

```text
templates/site_image_review_template.md
```

补充基地边界、道路、出入口、保留建筑、水体和限制条件。

### 第 3 步：发送开场问题

可以直接复制下面这段作为第一条消息：

```text
你现在是我的城乡规划方案共创助手。我会给你任务书和现状图信息。请先整理已知条件、未知条件、设计约束和机会点，不要直接给最终方案；然后给我 2–3 个可比较的概念方案，并说明每个方案适合怎么画成图。涉及规范时请只做风险提示，不要编造条文或审批结论。
```

### 第 4 步：继续迭代方案

推荐按这个顺序追问：

1. “请先做任务书解析和基地诊断。”
2. “请给我 3 个概念方案，并用表格比较。”
3. “我选择方案 B，请深化总平面结构。”
4. “请检查交通、消防、日照、停车、绿地等潜在规范风险。”
5. “请把最终方案转成总平面/鸟瞰/轴测/节点图的图像生成提示词。”

## 如果打不开网页怎么办

优先检查：

1. 启动服务的终端是否还开着。
2. 是否在仓库根目录运行了 `./scripts/start_web.sh`。
3. 端口是否是 `8000`。
4. 远程环境是否需要打开端口转发链接。
5. 端口被占用时，换端口启动：

```bash
PORT=8080 ./scripts/start_web.sh
```

然后打开：

```text
http://127.0.0.1:8080
```
