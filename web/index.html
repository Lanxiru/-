如何接入真实模型

  1. 前端收集任务书、约束、图片和输出阶段。
  2. 前端把文字和图片上传给自己的后端，不要在浏览器里暴露 API Key。
  3. 后端读取 prompts/system_prompt.md，组装 system prompt 与 user prompt。
  4. 如用户上传图片，后端调用多模态视觉模型先提取现状要素。
  5. 文本模型生成方案、表格、风险提示和图像提示词。
  6. 如需要直接出图，再把最终提示词发送给图像生成模型。
