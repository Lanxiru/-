## 输入信息

- 图像类型：总平面示意图 / 鸟瞰效果图 / 轴测分析图 / 节点人视图 / 剖面透视 / 概念拼贴
- 基地主题：
- 空间结构：
- 必须保留的现状要素：
- 主要功能分区：
- 交通系统：
- 景观与生态策略：
- 建筑形态与高度：
- 希望的表达风格：
- 画幅比例：1:1 / 4:3 / 16:9 / A1 横版 / A1 竖版

## 中文提示词

生成一张【图像类型】，【城市/基地背景】，【设计主题】。画面应清晰表现【空间结构】，包括【主要道路】、【慢行系统】、【功能分区】、【公共空间节点】、【绿地/水系/生态廊道】和【建筑体量】。保留【不可改变的现状要素】。表达风格为【风格】，构图【视角与比例】，色彩【色彩倾向】，包含适度规划图标、箭头、图例和清晰分区，但不要出现难以辨认的乱码文字。

## English Prompt

Create a 【image type】 for an urban and rural planning design of 【site context】, with the design concept of 【theme】. Clearly show 【spatial structure】, including 【main roads】, 【pedestrian and bicycle network】, 【land use zones】, 【public space nodes】, 【green-blue ecological corridors】, and 【building masses】. Preserve 【existing elements to keep】. Use a 【visual style】 presentation style, 【camera/view angle】 composition, 【color palette】 colors, with clean planning symbols, arrows, legends, and readable zoning graphics, avoiding random unreadable text.

## 负面提示词

乱码文字、错误比例、无关摩天楼、混乱道路、重复建筑、过度拥挤、水印、logo、低清晰度、脏污画面、畸形树木、车辆尺度错误、与现状边界不一致、遮挡主要规划结构。

## 参数建议

- 总平面示意图：正射俯视、少阴影、清晰边界、色块分区、适合 4:3 或 A1 横版。
- 鸟瞰效果图：45 度俯视、柔和日光、适度人群活动、适合 16:9。
- 轴测分析图：白底、透明体块、分层箭头、图例标签、适合 4:3。
- 节点人视图：1.6 米人眼高度、强调材质和活动，适合 16:9。
